# Apex Smart Solutions

Espaço de projeto da Apex Smart Solutions — terceirizada autorizada pela Claro,
vendendo planos, portabilidade, internet fixa e produtos de internet para
empresas (CNPJ).

Responsável: Rafael (desenvolvimento e planejamento).

## Escopo

O trabalho de Rafael cobre três frentes independentes, cada uma com seu
próprio ciclo de design (spec) → plano → implementação:

1. **Captação de leads** — URA (ligações automáticas), campanhas,
   formulários, tráfego pago.
2. **Capacitação de vendas** — estratégias para os consultores venderem
   mais.
3. **Ferramental interno** — dashboards, CRM e soluções com IA para
   otimizar operação e faturamento.

Cada frente ganha sua própria pasta/subprojeto conforme for iniciada, com
seu próprio design em `docs/superpowers/specs/`.

## Estrutura

```
apex-smart-solutions/
  docs/superpowers/specs/   # specs de design (uma por sub-projeto)
```
