# §149 TV Vendas — plano de implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** botão "Vendi!" (Discador/Renovação) e venda pelo status do lead alimentam, na hora, uma aba "TV Vendas" com o
ranking de conversão por consultor e as comemorações "VENDEU!" e "META BATIDA!", com conferência posterior na NEO.

**Architecture:** quatro migrations Postgres (Supabase `mdgfboijyqfkggcrhptn`, produção) criam `vendas_marcadas`,
`tv_meta_dia`, o cache de contatos, as RPCs secdef da TV, o gatilho do lead e a conferência via pg_cron. No
`_template.html` entra um bloco JS `vd*`/`tv*` (sem framework, como o resto do painel), um `<style id="tvStyles">`,
a aba nova e o botão flutuante. A TV pergunta a cada 3 s só `tv_ultima_venda()` (barato) e busca o resto quando muda.

**Tech Stack:** Postgres 15 + PL/pgSQL + pg_cron (Supabase), JS puro no `_template.html`, testes jsdom (`node test_*.js`
via `bash run_tests.sh`), conferências SQL que terminam com `raise exception 'RESULTADO: ...'` (desfazem tudo).

**Spec:** `docs/superpowers/specs/2026-11-12-tv-vendas-design.md` (§149). Ler antes de começar.

## Global Constraints

- Repo público: nada de CNPJ/telefone/nome real em teste ou SQL de conferência. Usar os CNPJs fictícios `11222333000181`
  e `11444777000161` (DV válido) e nomes começando com "Zz".
- Editar só `_template.html`. O `painel_clientes_apex.html` sai de `python build_painel.py`.
- Visual (CLAUDE.md): não tocar o `<style>` principal, o `aside.sidebar`, o `#pageHead`, o `ApexMotion`, o
  `mostrarAviso` nem o `fecharOverlay`. Classes reaproveitadas: `.card`, `.kpiGrid`/`.kpiCard`, `table.tbl`, `.btn`
  (`.btn-sm`, `.btn-outline`), `.field`, `.overlay`/`.modal`. Cores só por variável. O único tom novo é
  `--tv-ouro`/`--tv-ouro-claro`, declarado no `<style id="tvStyles">`. Verde só `--st-ganho`.
- **Botão "Vendi!":** a spec dizia "no topo, ao lado do usuário", mas o `#pageHead` e o `aside.sidebar` são
  protegidos. Ele vira um **botão flutuante** (canto inferior direito), visível em todas as abas.
- **Virada do dia:** a spec dizia "recarrega sozinha", mas recarregar tira a TV da tela cheia (o navegador exige
  clique para voltar). A aba **reinicia o próprio estado** na virada do dia, sem recarregar a página.
- **Migrations:** sem DROP (o conector do Supabase falha com DROP). Aplicar com `execute_sql` em `begin; … commit;`
  (`apply_migration` falha sempre). Policy/cron sempre em `do $$ … if not exists … $$`.
- **Banco de produção:** ler é livre. Escrever ou aplicar migration só com ok do Rafael na hora (Task 5).
  Publicar o painel, também só com ok (Task 12).
- **Hora de SP:** no banco, `(now() at time zone 'America/Sao_Paulo')`; no painel, `hojeSP()`. O cron do pg_cron é em
  UTC (SP = UTC−3).
- **Números:** linhas de 1 a 300 por item e no máximo 300 por pedido, valor por linha de R$ 20 a R$ 400, até 10 planos
  por pedido. O Desfazer vale 10 min. Tempos da TV: consulta a cada 3 s, ranking a cada 60 s, Alternar a cada 60 s,
  VENDEU! 7 s, META 10 s e aviso de sem conexão depois de 2 min. Conferência: 3 dias úteis
  (`boletim_dia_util`), cron às `25,55 11-23 * * *` UTC.
- Operação: só Apex (`coalesce(profiles.operacao,'apex') = 'apex'`; `discador_chamadas.operacao = 'apex'`).
- Venda de lead = `leads.categoria = 'convertido'` (status `PEDIDO CONCLUIDO (VENDA)`). A `leads_classificar` **não
  muda de assinatura**.

## Review Focus

1. **Duplo clique em "Confirmar venda 🎉"** deve gravar uma venda só. Teste na Task 7 (dois cliques, um `vendi`).
2. **Venda cancelada enquanto espera a vez na fila da TV** não pode ser comemorada. Teste na Task 6
   (`tvFiltrarFila`) e na Task 10 (fila com cancelado).
3. **TV sem internet por 30 min, depois volta.** Não pode soltar 30 VENDEU! seguidos de vendas velhas: só vendas dos
   últimos 15 min viram festa. Teste na Task 2 (SQL) e na Task 9 (aviso de sem conexão).
4. **Virada do dia com a TV ligada.** O "Hoje" troca de dia e as vendas de ontem não são comemoradas de novo. Teste na
   Task 9.
5. **Lead convertido com CNPJ vazio ou inválido** (147 leads hoje). A venda entra na TV com `cnpj` nulo e a
   conferência marca "não encontrada" depois do prazo, sem quebrar o gatilho. Teste na Task 3 (SQL).

```sql
-- §149 TV Vendas (12/11, Rafael) — parte 1: a venda nasce quando o consultor marca ("Vendi!") e a meta do dia.
-- Discador e Renovação marcam pelo vendi(); lead entra pelo gatilho da parte 3. A NEO só confere depois (parte 4).
-- Spec: docs/superpowers/specs/2026-11-12-tv-vendas-design.md. Sem DROP. Aplicar com execute_sql (begin/commit).
-- Conferência: supabase/tests/tv_vendas_base_check.sql (desfaz tudo).
begin;

create table if not exists public.vendas_marcadas (
  id                bigint generated always as identity primary key,
  consultor_id      uuid not null references public.profiles(id) on delete restrict,
  operacao          text not null default 'apex',
  origem            text not null check (origem in ('discador', 'renovacao', 'lead')),
  cnpj              text check (cnpj is null or cnpj ~ '^[0-9]{14}$'),   -- nulo só em venda de lead com CNPJ ruim
  itens             jsonb not null default '[]'::jsonb,                   -- [{plano_id, gb, valor_linha, linhas}]
  linhas            int not null default 0 check (linhas between 0 and 300),
  receita           numeric(12,2) not null check (receita >= 0),
  lead_aba          text,
  lead_id           text,
  dia               date not null default ((now() at time zone 'America/Sao_Paulo')::date),
  marcada_em        timestamptz not null default now(),
  marcada_por       uuid references public.profiles(id) on delete set null,
  cancelada_em      timestamptz,
  cancelada_por     uuid references public.profiles(id) on delete set null,
  motivo_cancel     text,
  neo_status        text not null default 'pendente' check (neo_status in ('pendente', 'confirmada', 'nao_encontrada', 'ok_gestor')),
  neo_pedido        text,
  neo_receita       numeric(12,2),
  neo_usuario       text,
  neo_conferida_em  timestamptz,
  neo_obs           text
);
create unique index if not exists vendas_marcadas_lead_ativa on public.vendas_marcadas (lead_aba, lead_id)
  where cancelada_em is null and lead_id is not null;
create index if not exists vendas_marcadas_op_dia on public.vendas_marcadas (operacao, dia);
create index if not exists vendas_marcadas_pendentes on public.vendas_marcadas (dia)
  where neo_status = 'pendente' and cancelada_em is null;
alter table public.vendas_marcadas enable row level security;   -- sem policy: só pelas funções
revoke all on table public.vendas_marcadas from public, anon, authenticated;

create table if not exists public.tv_meta_dia (
  dia            date primary key,
  meta           int not null check (meta > 0),
  definida_por   uuid references public.profiles(id) on delete set null,
  definida_em    timestamptz not null default now(),
  comemorada_em  timestamptz                       -- META BATIDA! uma vez por dia (tv_meta_comemorar)
);
alter table public.tv_meta_dia enable row level security;
revoke all on table public.tv_meta_dia from public, anon, authenticated;

create or replace function public.tv_hoje()
 returns date language sql stable set search_path to 'public'
as $$ select (now() at time zone 'America/Sao_Paulo')::date $$;

-- Quem vê a TV e a conferência: admin, ou supervisor da operação Apex.
create or replace function public.tv_eh_gestor()
 returns boolean language sql stable security definer set search_path to 'public'
as $$
  select exists (select 1 from public.profiles p where p.id = auth.uid()
                  and (p.role = 'admin' or (p.role = 'supervisor' and coalesce(p.operacao, 'apex') = 'apex')))
$$;

-- Itens do pedido: confere e soma (receita = Σ linhas × valor_linha). O valor vem do painel (OFFERS_MOBILE);
-- aqui só a faixa de sanidade.
create or replace function public.vendas_itens_normalizar(p_itens jsonb, out itens jsonb, out linhas int, out receita numeric)
 language plpgsql immutable set search_path to 'public'
as $function$
declare i jsonb; v_l int; v_v numeric; v_gb numeric; v_n int := 0;
begin
  if p_itens is null or jsonb_typeof(p_itens) <> 'array' or jsonb_array_length(p_itens) = 0 then
    raise exception 'Escolha pelo menos um plano.' using errcode = '22023';
  end if;
  if jsonb_array_length(p_itens) > 10 then raise exception 'No máximo 10 planos por pedido.' using errcode = '22023'; end if;
  itens := '[]'::jsonb; linhas := 0; receita := 0;
  for i in select e from jsonb_array_elements(p_itens) e loop
    v_n := v_n + 1;
    begin
      v_l := (i ->> 'linhas')::int;
      v_v := round((i ->> 'valor_linha')::numeric, 2);
      v_gb := nullif(i ->> 'gb', '')::numeric;
    exception when others then
      raise exception 'Plano %: linhas ou valor inválido.', v_n using errcode = '22023';
    end;
    if coalesce(i ->> 'plano_id', '') = '' then raise exception 'Plano %: escolha o plano.', v_n using errcode = '22023'; end if;
    if v_l is null or v_l < 1 or v_l > 300 then raise exception 'Plano %: linhas de 1 a 300.', v_n using errcode = '22023'; end if;
    if v_v is null or v_v < 20 or v_v > 400 then
      raise exception 'Plano %: valor por linha fora da faixa (R$ 20 a R$ 400).', v_n using errcode = '22023';
    end if;
    linhas := linhas + v_l;
    receita := receita + v_l * v_v;
    itens := itens || jsonb_build_array(jsonb_build_object('plano_id', i ->> 'plano_id', 'gb', v_gb, 'valor_linha', v_v, 'linhas', v_l));
  end loop;
  if linhas > 300 then raise exception 'No máximo 300 linhas por pedido.' using errcode = '22023'; end if;
  receita := round(receita, 2);
end $function$;

create or replace function public.vendi(p_cnpj text, p_itens jsonb, p_origem text)
 returns jsonb language plpgsql security definer set search_path to 'public'
as $function$
declare v_eu record; v_dig text; v_n record; v_id bigint; v_aviso text; v_hora timestamptz;
begin
  select p.id, p.role, coalesce(p.operacao, 'apex') as operacao into v_eu from public.profiles p where p.id = auth.uid();
  if v_eu.id is null then raise exception 'sem login' using errcode = '42501'; end if;
  if v_eu.role not in ('consultor', 'supervisor', 'admin') or (v_eu.role <> 'admin' and v_eu.operacao <> 'apex') then
    raise exception 'sem permissão' using errcode = '42501';
  end if;
  if p_origem is null or p_origem not in ('discador', 'renovacao') then raise exception 'origem inválida' using errcode = '22023'; end if;
  v_dig := regexp_replace(coalesce(p_cnpj, ''), '[^0-9]', '', 'g');
  if not public.leads_cnpj_valido(v_dig) then raise exception 'CNPJ inválido: confira os 14 números.' using errcode = '22023'; end if;
  select * into v_n from public.vendas_itens_normalizar(p_itens);
  select min(v.marcada_em) into v_hora from public.vendas_marcadas v
   where v.consultor_id = v_eu.id and v.cnpj = v_dig and v.dia = public.tv_hoje() and v.cancelada_em is null;
  if v_hora is not null then
    v_aviso := 'Você já marcou este CNPJ hoje às ' || to_char(v_hora at time zone 'America/Sao_Paulo', 'HH24:MI') || '. Se foi engano, use Desfazer.';
  elsif exists (select 1 from public.vendas_marcadas v where v.cnpj = v_dig and v.origem = 'lead'
                  and v.dia = public.tv_hoje() and v.cancelada_em is null) then
    v_aviso := 'Este CNPJ já virou venda por um lead hoje. Se foi engano, use Desfazer.';
  end if;
  insert into public.vendas_marcadas (consultor_id, operacao, origem, cnpj, itens, linhas, receita, marcada_por)
  values (v_eu.id, 'apex', p_origem, v_dig, v_n.itens, v_n.linhas, v_n.receita, v_eu.id)
  returning id into v_id;
  return jsonb_build_object('id', v_id, 'receita', v_n.receita, 'linhas', v_n.linhas, 'aviso', v_aviso);
end $function$;

create or replace function public.vendi_cancelar(p_id bigint, p_motivo text)
 returns void language plpgsql security definer set search_path to 'public'
as $function$
declare v record; v_gestor boolean := public.tv_eh_gestor();
begin
  if auth.uid() is null then raise exception 'sem login' using errcode = '42501'; end if;
  select * into v from public.vendas_marcadas where id = p_id for update;
  if not found then raise exception 'venda não encontrada' using errcode = 'P0002'; end if;
  if v.cancelada_em is not null then raise exception 'Esta venda já foi cancelada.' using errcode = '22023'; end if;
  if v.origem = 'lead' then raise exception 'Venda de lead: mude o status do lead para tirar a venda.' using errcode = '22023'; end if;
  if v_gestor then
    if length(trim(coalesce(p_motivo, ''))) < 3 then raise exception 'Escreva o motivo (pelo menos 3 letras).' using errcode = '22023'; end if;
  elsif v.consultor_id = auth.uid() then
    if now() - v.marcada_em > interval '10 minutes' then
      raise exception 'Passou de 10 minutos: peça ao gestor para cancelar.' using errcode = '42501';
    end if;
  else
```

```sql
create or replace function public.tv_contatos_calc(p_de date, p_ate date)
 returns table(dia date, profile_id uuid, contatos int)
 language sql stable security definer set search_path to 'public'
as $$
  with disc as (
    select (d.gerada_em at time zone 'America/Sao_Paulo')::date as dia, a.profile_id,
           coalesce(nullif(regexp_replace(coalesce(d.cnpj, ''), '\D', '', 'g'), ''), 'ch' || d.id) as chave
      from public.discador_chamadas d
      join public.discador_agente a on a.agente_id = d.agente_id and a.profile_id is not null
     where d.operacao = 'apex'
       and d.gerada_em >= (p_de::timestamp at time zone 'America/Sao_Paulo')
       and d.gerada_em <  ((p_ate + 1)::timestamp at time zone 'America/Sao_Paulo')
       and d.tabulacao is not null and d.tabulacao <> 'SEM CONTATO'
  ), lds as (
    select (h.em at time zone 'America/Sao_Paulo')::date as dia, h.por as profile_id,
           coalesce(nullif(regexp_replace(coalesce(l.cnpj, ''), '\D', '', 'g'), ''), 'ld' || h.lead_aba || '|' || h.lead_id) as chave
      from public.leads_historico h
      join public.leads l on l.aba = h.lead_aba and l.id = h.lead_id
     where h.acao = 'classificar' and h.por is not null
       and h.em >= (p_de::timestamp at time zone 'America/Sao_Paulo')
       and h.em <  ((p_ate + 1)::timestamp at time zone 'America/Sao_Paulo')
  )
  select x.dia, x.profile_id, count(distinct x.chave)::int
    from (select * from disc union all select * from lds) x
   group by x.dia, x.profile_id
$$;

create or replace function public.tv_contatos(p_de date, p_ate date)
 returns table(profile_id uuid, contatos int)
 language plpgsql security definer set search_path to 'public'
as $function$
#variable_conflict use_column
declare v_corte date := public.tv_hoje() - 2; v_dia date;
begin
  for v_dia in select g::date from generate_series(p_de, least(p_ate, v_corte), interval '1 day') g loop
    if not exists (select 1 from public.tv_contatos_cache_dias c where c.dia = v_dia) then
      insert into public.tv_contatos_cache (dia, profile_id, contatos)
        select t.dia, t.profile_id, t.contatos from public.tv_contatos_calc(v_dia, v_dia) t
        on conflict (dia, profile_id) do update set contatos = excluded.contatos;
      insert into public.tv_contatos_cache_dias (dia) values (v_dia) on conflict (dia) do nothing;
    end if;
  end loop;
  return query
    select s.pid, sum(s.n)::int from (
      select c.profile_id as pid, c.contatos as n from public.tv_contatos_cache c
       where c.dia between p_de and least(p_ate, v_corte)
      union all
      select t.profile_id, t.contatos from public.tv_contatos_calc(greatest(p_de, v_corte + 1), p_ate) t
       where p_ate > v_corte
    ) s group by s.pid;
end $function$;

-- Posição no ranking do mês contando só as vendas até p_ate_id (ordem: vendas, depois receita). Nula sem venda.
create or replace function public.tv_posicao_mes(p_consultor uuid, p_ate_id bigint, p_de date, p_ate date)
 returns int language sql stable security definer set search_path to 'public'
as $$
  with v as (
    select x.consultor_id, count(*) as n, sum(x.receita) as r
      from public.vendas_marcadas x
     where x.operacao = 'apex' and x.cancelada_em is null and x.dia between p_de and p_ate and x.id <= p_ate_id
     group by x.consultor_id
  ), o as (select v.consultor_id, rank() over (order by v.n desc, v.r desc) as pos from v)
  select o.pos::int from o where o.consultor_id = p_consultor
$$;

create or replace function public.tv_ranking(p_periodo text)
 returns jsonb language plpgsql security definer set search_path to 'public'
as $function$
declare v_hoje date := public.tv_hoje(); v_de date; v_linhas jsonb; v_tot jsonb; v_ult jsonb; v_meta jsonb;
begin
  if not public.tv_eh_gestor() then raise exception 'sem permissão' using errcode = '42501'; end if;
  if p_periodo is null or p_periodo not in ('hoje', 'mes') then raise exception 'período inválido' using errcode = '22023'; end if;
  v_de := case when p_periodo = 'hoje' then v_hoje else date_trunc('month', v_hoje)::date end;
  with cont as (select * from public.tv_contatos(v_de, v_hoje)),
  vend as (
    select v.consultor_id, count(*)::int as vendas, sum(v.receita) as receita
      from public.vendas_marcadas v
     where v.operacao = 'apex' and v.cancelada_em is null and v.dia between v_de and v_hoje
     group by v.consultor_id
  ), base as (
    select p.id, p.nome, coalesce(c.contatos, 0) as contatos, coalesce(x.vendas, 0) as vendas, coalesce(x.receita, 0) as receita
      from public.profiles p
      left join cont c on c.profile_id = p.id
      left join vend x on x.consultor_id = p.id
     where coalesce(p.operacao, 'apex') = 'apex'
       and ((p.role = 'consultor' and (coalesce(c.contatos, 0) > 0 or coalesce(x.vendas, 0) > 0)) or coalesce(x.vendas, 0) > 0)
  ), ord as (
    select b.*, case when b.vendas > 0 then rank() over (partition by (b.vendas > 0) order by b.vendas desc, b.receita desc) end as posicao
      from base b
  )
  select coalesce(jsonb_agg(jsonb_build_object('profile_id', o.id, 'nome', o.nome, 'contatos', o.contatos, 'vendas', o.vendas,
             'receita', o.receita, 'conversao', case when o.contatos > 0 then round(100.0 * o.vendas / o.contatos, 1) end,
             'posicao', o.posicao) order by o.vendas desc, o.receita desc, o.contatos desc, o.nome), '[]'::jsonb),
         jsonb_build_object('contatos', coalesce(sum(o.contatos), 0), 'vendas', coalesce(sum(o.vendas), 0),
             'receita', coalesce(sum(o.receita), 0),
             'conversao', case when sum(o.contatos) > 0 then round(100.0 * sum(o.vendas) / sum(o.contatos), 1) end)
    into v_linhas, v_tot
    from ord o;
  v_meta := jsonb_build_object('dia', v_hoje, 'meta', public.tv_meta_atual(),
    'vendas_hoje', (select count(*) from public.vendas_marcadas v where v.operacao = 'apex' and v.cancelada_em is null and v.dia = v_hoje));
  select jsonb_build_object('nome', p.nome, 'em', v.marcada_em) into v_ult
    from public.vendas_marcadas v join public.profiles p on p.id = v.consultor_id
   where v.operacao = 'apex' and v.cancelada_em is null order by v.id desc limit 1;
  return jsonb_build_object('periodo', p_periodo, 'de', v_de, 'ate', v_hoje, 'linhas', v_linhas, 'totais', v_tot,
                            'meta', v_meta, 'ultima', v_ult, 'gerado_em', now());
end $function$;

-- Vendas novas para o VENDEU!: só de hoje, não canceladas e dos últimos 15 min (TV que ficou sem internet não
-- solta festa de venda velha). No máximo 20 por chamada.
create or replace function public.tv_vendas_desde(p_id bigint)
 returns jsonb language plpgsql security definer set search_path to 'public'
as $function$
declare v_hoje date := public.tv_hoje(); v_mes date := date_trunc('month', public.tv_hoje())::date;
        r record; v_out jsonb := '[]'::jsonb; v_cts jsonb; v_ct int; v_vh int;
begin
  if not public.tv_eh_gestor() then raise exception 'sem permissão' using errcode = '42501'; end if;
  select coalesce(jsonb_object_agg(t.profile_id::text, t.contatos), '{}'::jsonb) into v_cts
    from public.tv_contatos_calc(v_hoje, v_hoje) t;
  for r in
    select v.id, v.consultor_id, v.receita, v.origem, p.nome
      from public.vendas_marcadas v join public.profiles p on p.id = v.consultor_id
     where v.operacao = 'apex' and v.id > coalesce(p_id, 0) and v.cancelada_em is null and v.dia = v_hoje
       and v.marcada_em > now() - interval '15 minutes'
     order by v.id limit 20
  loop
    select count(*) into v_vh from public.vendas_marcadas x
     where x.consultor_id = r.consultor_id and x.operacao = 'apex' and x.cancelada_em is null and x.dia = v_hoje and x.id <= r.id;
    v_ct := coalesce((v_cts ->> r.consultor_id::text)::int, 0);
    v_out := v_out || jsonb_build_array(jsonb_build_object(
      'id', r.id, 'consultor_id', r.consultor_id, 'nome', r.nome, 'receita', r.receita, 'origem', r.origem,
      'vendas_hoje', v_vh, 'contatos_hoje', v_ct,
      'conversao_hoje', case when v_ct > 0 then round(100.0 * v_vh / v_ct, 1) end,
      'pos_antes', public.tv_posicao_mes(r.consultor_id, r.id - 1, v_mes, v_hoje),
      'pos_depois', public.tv_posicao_mes(r.consultor_id, r.id, v_mes, v_hoje)));
  end loop;
  return v_out;
end $function$;

create or replace function public.tv_meta_definir(p_meta int)
 returns void language plpgsql security definer set search_path to 'public'
as $function$
begin
  if not public.tv_eh_gestor() then raise exception 'sem permissão' using errcode = '42501'; end if;
  if p_meta is null or p_meta < 1 or p_meta > 1000 then raise exception 'Meta de 1 a 1000 vendas.' using errcode = '22023'; end if;

  on conflict (dia) do update set meta = excluded.meta, definida_por = excluded.definida_por, definida_em = now();
end $function$;

-- "Sim" uma vez por dia, quando as vendas de hoje chegam na meta (update … where comemorada_em is null).
create or replace function public.tv_meta_comemorar()
 returns jsonb language plpgsql security definer set search_path to 'public'
as $function$
declare v_hoje date := public.tv_hoje(); v_meta int := public.tv_meta_atual(); v_vendas int; v_ok timestamptz; v_pessoas jsonb;
begin
  if not public.tv_eh_gestor() then raise exception 'sem permissão' using errcode = '42501'; end if;
  if v_meta is null then return jsonb_build_object('comemorar', false); end if;
  select count(*) into v_vendas from public.vendas_marcadas v where v.operacao = 'apex' and v.cancelada_em is null and v.dia = v_hoje;
  if v_vendas < v_meta then return jsonb_build_object('comemorar', false, 'vendas', v_vendas, 'meta', v_meta); end if;
  insert into public.tv_meta_dia (dia, meta) values (v_hoje, v_meta) on conflict (dia) do nothing;
  update public.tv_meta_dia set comemorada_em = now() where dia = v_hoje and comemorada_em is null returning comemorada_em into v_ok;
  if v_ok is null then return jsonb_build_object('comemorar', false, 'vendas', v_vendas, 'meta', v_meta); end if;
  select coalesce(jsonb_agg(jsonb_build_object('nome', x.nome, 'vendas', x.n) order by x.n desc, x.nome), '[]'::jsonb) into v_pessoas
```

```sql
-- Gatilho em leads: entrou em 'convertido' por uma classificação → cria; saiu de 'convertido' ou foi apagado → cancela;
-- continua 'convertido' → acompanha receita e CNPJ (§147). A receita que vale é a do lead (§140); os itens (plano ×
-- linhas) chegam depois pela venda_itens_lead (o Classificar chama logo depois da leads_classificar, que não muda).

create or replace function public.vendas_marcadas_do_lead()
 returns trigger language plpgsql security definer set search_path to 'public'
as $function$
declare v_cons uuid := coalesce(new.dono_id, new.classificado_por);
        v_dig text := regexp_replace(coalesce(new.cnpj, ''), '[^0-9]', '', 'g');
        v_cnpj text;
begin
  v_cnpj := case when public.leads_cnpj_valido(v_dig) then v_dig end;
  if new.apagado_em is not null and old.apagado_em is null then
    update public.vendas_marcadas set cancelada_em = now(), cancelada_por = auth.uid(), motivo_cancel = 'lead apagado'
     where lead_aba = new.aba and lead_id = new.id and cancelada_em is null;
    return null;
  end if;
  if new.categoria = 'convertido' and old.categoria is distinct from 'convertido' then
    if new.classificado_em is distinct from old.classificado_em and v_cons is not null and new.apagado_em is null then
      insert into public.vendas_marcadas (consultor_id, operacao, origem, cnpj, receita, lead_aba, lead_id, marcada_por)
      select v_cons, coalesce(p.operacao, 'apex'), 'lead', v_cnpj, greatest(coalesce(new.receita, 0), 0), new.aba, new.id, new.classificado_por
        from public.profiles p where p.id = v_cons
      on conflict (lead_aba, lead_id) where cancelada_em is null and lead_id is not null do nothing;
    end if;
  elsif old.categoria = 'convertido' and new.categoria is distinct from 'convertido' then
    update public.vendas_marcadas set cancelada_em = now(), cancelada_por = new.classificado_por, motivo_cancel = 'lead mudou de status'
     where lead_aba = new.aba and lead_id = new.id and cancelada_em is null;
  elsif new.categoria = 'convertido' then
    update public.vendas_marcadas
       set receita = greatest(coalesce(new.receita, 0), 0), cnpj = coalesce(v_cnpj, cnpj)
     where lead_aba = new.aba and lead_id = new.id and cancelada_em is null
       and (receita is distinct from greatest(coalesce(new.receita, 0), 0) or cnpj is distinct from coalesce(v_cnpj, cnpj));
  end if;
  return null;
end $function$;

do $$
begin
  if not exists (select 1 from pg_trigger where tgname = 'vendas_marcadas_lead' and tgrelid = 'public.leads'::regclass) then
    create trigger vendas_marcadas_lead
      after update of categoria, receita, cnpj, classificado_em, apagado_em on public.leads
      for each row execute function public.vendas_marcadas_do_lead();
  end if;
end $$;

   where lead_aba = p_aba and lead_id = p_id and cancelada_em is null;
end $function$;

revoke all on function public.vendas_marcadas_do_lead() from public, anon, authenticated;
revoke all on function public.venda_itens_lead(text, text, jsonb) from public, anon;
grant execute on function public.venda_itens_lead(text, text, jsonb) to authenticated;

commit;
```

```sql
-- §149 TV Vendas — parte 4: a NEO confere depois, sem tirar comemoração do ar.
-- A cada 30 min (8h–21h de SP): venda pendente com pedido no NEO no mesmo CNPJ, entre o dia da marcação e +3 dias úteis
-- (sem perdido/devolvido; GROSS já não entra, §49) → confirmada; passou do prazo → nao_encontrada. Nada é cancelado
-- sozinho: o gestor decide no bloco Conferência. Fora da sync-producao de propósito (§81 pendente).
-- Sem DROP. Aplicar com execute_sql (begin/commit). Conferência: supabase/tests/tv_vendas_conferencia_check.sql.
begin;

create index if not exists idx_producao_neo_cnpj on public.producao_pedidos_neo (cnpj);

create or replace function public.tv_dia_util_mais(p_dia date, p_n int)
 returns date language plpgsql immutable set search_path to 'public'
as $function$
declare d date := p_dia; k int := 0;
begin
  while k < p_n loop
    d := d + 1;
    if public.boletim_dia_util(d) then k := k + 1; end if;
  end loop;
  return d;
end $function$;

create or replace function public.vendas_conferir_neo()
 returns int language plpgsql security definer set search_path to 'public'
as $function$
declare v record; v_n int := 0; v_hoje date := public.tv_hoje(); v_prazo date;
        v_ped text; v_rec numeric; v_usu text;
begin
  for v in
    select x.id, x.cnpj, x.dia from public.vendas_marcadas x
     where x.neo_status = 'pendente' and x.cancelada_em is null
     order by x.id for update skip locked
  loop
    v_prazo := public.tv_dia_util_mais(v.dia, 3);
    v_ped := null; v_rec := null; v_usu := null;
    if v.cnpj is not null then
      select n.numero_pedido, round(sum(coalesce(n.valor, 0)), 2), min(n.usuario)
        into v_ped, v_rec, v_usu
        from public.producao_pedidos_neo n
       where n.cnpj = v.cnpj and n.numero_pedido is not null
         and n.etapa not in ('VENDA PERDIDA (NEOCRM)', 'DEVOLVIDO (NEOCRM)')
         and (n.cadastro at time zone 'America/Sao_Paulo')::date between v.dia and v_prazo
       group by n.numero_pedido
       order by min(n.cadastro)
       limit 1;
    end if;
    if v_ped is not null then
      update public.vendas_marcadas set neo_status = 'confirmada', neo_pedido = v_ped, neo_receita = v_rec,
             neo_usuario = v_usu, neo_conferida_em = now() where id = v.id;
      v_n := v_n + 1;
    elsif v_hoje > v_prazo then
      update public.vendas_marcadas set neo_status = 'nao_encontrada', neo_conferida_em = now() where id = v.id;
      v_n := v_n + 1;
    end if;
  end loop;
  return v_n;
end $function$;

create or replace function public.tv_conferencia()
 returns jsonb language plpgsql stable security definer set search_path to 'public'
as $function$
begin
  if not public.tv_eh_gestor() then raise exception 'sem permissão' using errcode = '42501'; end if;
  return coalesce((
    select jsonb_agg(to_jsonb(x) order by x.dia desc, x.id desc) from (
      select v.id, v.dia, v.cnpj, v.receita, v.origem, v.neo_status, v.neo_pedido, v.neo_receita, v.neo_usuario, p.nome,
             case
               when v.neo_status = 'nao_encontrada' then 'Sem pedido na NEO em 3 dias úteis'
```

```js
// ===== §149 TV Vendas (12/11, Rafael): "Vendi!", ranking ao vivo e comemorações =====
// Spec: docs/superpowers/specs/2026-11-12-tv-vendas-design.md. Prefixos: vd = botão/janela Vendi!, tv = aba TV Vendas.
const TV_TEMPOS = { tick: 3000, ranking: 60000, alternar: 60000, relogio: 1000, vendeu: 7000, meta: 10000, semConexao: 120000, desfazer: 600000, mini: 2000 };
function vdOfertas(){
  return OFFERS_MOBILE.map(o => ({ id: o.id, gb: o.gb, valor: o.valor,
    rotulo: `${o.gb}GB · ${fmtBRL(o.valor)}${o.origem === 'Nacional' ? '' : ' · ' + o.origem}` }));
}
function vdReceita(itens){
  const centavos = (itens || []).reduce((s, i) => s + Math.round((Number(i.valor_linha) || 0) * 100) * (Number(i.linhas) || 0), 0);
  return centavos / 100;
}
// Mesmas mensagens do vendas_itens_normalizar() no banco.
function vdItensErro(itens){
  if(!itens || !itens.length) return 'Escolha pelo menos um plano.';
  if(itens.length > 10) return 'No máximo 10 planos por pedido.';
  for(let k = 0; k < itens.length; k++){
    const i = itens[k], n = k + 1;
    if(!i.plano_id) return `Plano ${n}: escolha o plano.`;
    if(!Number.isInteger(i.linhas) || i.linhas < 1 || i.linhas > 300) return `Plano ${n}: linhas de 1 a 300.`;
  }
  if(itens.reduce((s, i) => s + i.linhas, 0) > 300) return 'No máximo 300 linhas por pedido.';
  return '';
}
function tvIniciais(nome){
  const p = String(nome || '').trim().split(/\s+/).filter(Boolean);
  if(!p.length) return '?';
  return (p[0][0] + (p.length > 1 ? p[p.length - 1][0] : '')).toUpperCase();
}
function tvConversaoTxt(pct){ return pct === null || pct === undefined ? '—' : Number(pct).toFixed(1).replace('.', ',') + '%'; }
function tvTextoSubida(v){
  const a = v && v.pos_antes, d = v && v.pos_depois;
  if(!d) return '';
  if(!a) return `▲ entrou em ${d}º lugar no mês`;
  if(d < a) return `▲ subiu do ${a}º para o ${d}º lugar no mês`;
  return `manteve o ${d}º lugar no mês`;
}
// Movimento de posição entre dois rankings: +n subiu, −n desceu, null entrou agora, 0 parado ou sem venda.
function tvSetas(antes, depois){
  const pos = new Map((antes || []).filter(l => l.posicao).map(l => [l.profile_id, l.posicao]));
  const out = {};
  (depois || []).forEach(l => {
    const a = pos.get(l.profile_id);
    out[l.profile_id] = !l.posicao ? 0 : (a ? a - l.posicao : null);
  });
  return out;
}
function tvFiltrarFila(fila, cancelados){
  const fora = new Set(cancelados || []);
  return (fila || []).filter(v => !fora.has(v.id));
}
```

```js
  ranking: null, setas: {}, fila: [], festando: false, metaFeita: null, timers: [], ultimaOk: 0, dia: null };
function canSeeTvVendas(){ return !!currentUser && (currentUser.role === 'admin' || (currentUser.role === 'supervisor' && minhaOperacao() === 'apex')); }
function tvAplicarPermissao(){
  document.getElementById('tabBtnTvVendas').style.display = canSeeTvVendas() ? 'inline-block' : 'none';
  tvParar();
}
function tvParar(){
  tvEstado.ativo = false; tvEstado.ger++;
  tvEstado.timers.forEach(t => clearInterval(t)); tvEstado.timers = [];
  tvEstado.fila = []; tvEstado.festando = false;
  const f = document.getElementById('tvFesta'); if(f){ f.hidden = true; f.innerHTML = ''; }
}
async function tvAbrir(){
  if(!canSeeTvVendas()) return;
  tvParar();
  Object.assign(tvEstado, { ativo: true, dia: hojeSP(), ultimoId: null, cancelados: '[]', ranking: null, setas: {}, ultimaOk: Date.now() });
  try{ tvEstado.som = window.localStorage.getItem('tvSom') === '1'; }catch(_e){ /* sem localStorage: som desligado */ }
  tvRenderBotoes();
  tvRelogio();
  const g = tvEstado.ger;
  await tvTick();
  if(g !== tvEstado.ger) return;
  await tvCarregarRanking();
  if(g !== tvEstado.ger) return;
  if(typeof tvCarregarConferencia === 'function') tvCarregarConferencia();
  const cada = (fn, ms) => tvEstado.timers.push(setInterval(() => { if(g === tvEstado.ger) fn(); }, ms));
  cada(tvTick, TV_TEMPOS.tick);
  cada(tvCarregarRanking, TV_TEMPOS.ranking);
  cada(() => { if(tvEstado.alternar && !tvEstado.festando) tvTrocarPeriodo(tvEstado.periodo === 'hoje' ? 'mes' : 'hoje'); }, TV_TEMPOS.alternar);
  cada(tvRelogio, TV_TEMPOS.relogio);
}
function tvRelogio(){
  const el = document.getElementById('tvHora');
  if(el) el.textContent = new Date().toLocaleTimeString('pt-BR', { timeZone: 'America/Sao_Paulo', hour: '2-digit', minute: '2-digit' });
}
// Virada do dia: reinicia o estado sem recarregar a página (recarregar tiraria a TV da tela cheia).
function tvVirarDia(){ tvAbrir(); }
async function tvTick(){
  if(tvEstado.dia && hojeSP() !== tvEstado.dia){ tvVirarDia(); return; }
  const g = tvEstado.ger;
  const r = await ppSeguro(() => sb.rpc('tv_ultima_venda'));
  if(g !== tvEstado.ger) return;
  if(!r || r.error || !r.data){ tvConexao(false); return; }
  tvConexao(true);
  const d = r.data, id = Number(d.ultimo_id) || 0, canc = JSON.stringify(d.cancelados_ids || []);
  if(tvEstado.ultimoId === null){ tvEstado.ultimoId = id; tvEstado.cancelados = canc; tvEstado.meta = d.meta; return; }
  let mudou = canc !== tvEstado.cancelados || d.meta !== tvEstado.meta;
  tvEstado.cancelados = canc; tvEstado.meta = d.meta;
  tvEstado.fila = tvFiltrarFila(tvEstado.fila, d.cancelados_ids);
  if(id > tvEstado.ultimoId){
    const n = await ppSeguro(() => sb.rpc('tv_vendas_desde', { p_id: tvEstado.ultimoId }));
    if(g !== tvEstado.ger) return;
    if(n && !n.error && Array.isArray(n.data)){
      tvEstado.ultimoId = n.data.length === 20 ? n.data[19].id : id;   // 20 = limite do banco: o resto vem no próximo tick
      tvEstado.fila.push(...n.data);
      mudou = true;
    }
  }
  if(mudou){ await tvCarregarRanking(); if(g === tvEstado.ger) tvProximaFesta(); }
}
function tvConexao(ok){
  const av = document.getElementById('tvSemConexao');
  if(ok){ tvEstado.ultimaOk = Date.now(); if(av) av.hidden = true; return; }
  const min = Math.floor((Date.now() - tvEstado.ultimaOk) / 60000);
  if(av && Date.now() - tvEstado.ultimaOk > TV_TEMPOS.semConexao){
    av.textContent = `Sem conexão há ${Math.max(min, 1)} min — os números podem estar parados.`;
    av.hidden = false;
  }
}
async function tvCarregarRanking(){
  const g = tvEstado.ger, per = tvEstado.periodo;
  const r = await ppSeguro(() => sb.rpc('tv_ranking', { p_periodo: per }));
  if(g !== tvEstado.ger || per !== tvEstado.periodo) return;
  if(!r || r.error || !r.data){ tvConexao(false); return; }
  tvConexao(true);
  const novo = r.data;
  if(tvEstado.ranking && tvEstado.ranking.periodo === novo.periodo){
    const s = tvSetas(tvEstado.ranking.linhas, novo.linhas);
    if(Object.values(s).some(x => x !== 0)) tvEstado.setas = s;   // guarda o último movimento até o próximo
  } else tvEstado.setas = {};
  tvEstado.ranking = novo;
  tvRender();
}

  tvEstado.periodo = p; tvEstado.ranking = null; tvEstado.setas = {};

  tvCarregarRanking();
```
