Proposta avulsa

Gere uma proposta para um cliente que ainda não está na base — de outra operadora que você está tentando conquistar, ou um cliente Claro pessoa física migrando para pessoa jurídica. Informe os dados abaixo; a "Situação atual" da proposta usa o valor que o próprio cliente informou pagar hoje. Na tela seguinte você define quantas linhas de cada tipo (linha nova ou portabilidade) o cliente vai levar — pode misturar os dois, ex.: 3 linhas de portabilidade + 3 linhas novas.
